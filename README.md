# Exporty

Export Discord chat logs to CSV, HTML, JSON, and TXT fast, local, and unlimited and for free.

## Features

- Export Discord messages from any channel or DM
- Export formats: Plain Text, CSV, JSON, HTML
- Time range filtering export specific date ranges
- Dark and light theme with system auto-detection
- Works with guild channels and direct messages
- All processing is local

## Installation

0. Download as zip this repo and unzip it
1. Open Chrome and navigate to `chrome://extensions`
2. Enable **Developer mode** 
3. Click **Load unpacked**
4. Select the `exporty` folder

## Usage

1. Navigate to any Discord channel or DM in your browser
2. Click the Exporty extension icon
3. Select your preferred file format
4. Optionally set a date range
5. Click **Export** your chat will download automatically
